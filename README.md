# 파이널 판타지 X 인터내셔널 한글패치
## 파이널 판타지 X 인터내셔널 한글패치 v0.2.0

두 번째 시험 배포판입니다. v0.1 이후 플레이 중 발견된 진행 불가 오류와 표기 오류를 고쳤습니다.

## 다운로드

- 파일: `[KR Patch] Final Fantasy X-international_v0.2.0.zip`
- 내용: 패치 파일, 적용 도구, 설명서

압축 안에 든 파일 다섯 개입니다.

- `패치적용.bat` - 더블클릭으로 패치를 적용합니다
- `FFX_International_JP_한글패치_v0.2.0.xdelta` - 패치 본체
- `xdelta3.exe` - 패치 적용 도구 (xdelta 3.2.0 공식 배포본)
- `README_한글패치_v0.2.0.txt` - 설명서
- `FFX_International_JP_한글패치_v0.2.0.xdelta.md5.txt` - 검증용 MD5

## 원본 ISO

- 게임: Final Fantasy X International (일본판, SLPS-25088)
- 크기: 4,613,767,168 바이트
- 원본 MD5: `4033e9f641f0385f42fb9e04a20adbbe`
- 적용 결과 MD5: `c478682a1cbda56139c318f2f7e7caeb`

원본 MD5 가 다르면 적용되지 않습니다.

## 적용 방법

1. zip 파일을 빈 폴더에 풉니다.
2. 원본 ISO 를 같은 폴더에 넣습니다.
3. `패치적용.bat` 를 더블클릭합니다. 원본 ISO 를 bat 파일 위로 끌어다 놓아도 됩니다.
4. 잠시 뒤 `FFX_International_JP_KOR.iso` 가 생깁니다.

명령줄로 직접 적용하려면 아래와 같이 씁니다.

```
xdelta3.exe -d -B 1073741824 -s "원본.iso" "FFX_International_JP_한글패치_v0.2.0.xdelta" "FFX_International_JP_KOR.iso"
```

## 변경 사항 (v0.1 이후)

진행 불가, 다운 오류

- 블리츠볼 시합 멈춤: 패스를 받은 선수의 슛 수치가 계속 바뀌며 조작이 안 되던 문제를 고쳤습니다.
- 몬스터 훈련장 전투 진입 다운: 일부 훈련장 전투에 들어갈 때 멈추던 문제를 고쳤습니다.

화면, 글 오류

- 초코보 레이스 결과창: 기록과 풍선 수 자리에 느낌표만 찍히던 문제를 고쳤습니다.
- 블리츠볼 대진표: VS 위치를 원래 자리로 되돌렸습니다.
- 씬 대사 글자 뒤틀림: 21개 장면 36줄에서 다른 글자로 보이던 문제를 고쳤습니다.
- 몬스터 이름 글자: 전투 화면에서 「보」가 「멈」으로 보이던 문제를 고쳤습니다. 「멈반」은 「보반」, 「요짐멈」은 「요짐보」, 전투 도움말 「사멈텐더」는 「사보텐더」로 나옵니다.
- 화자 이름 뒤 글자: 리키호와 블리츠볼 장면에서 「보츠」, 「닷트」, 「아나운서」 등 이름 뒤에 붙던 엉뚱한 글자를 없앴습니다.
- 「버섯」: 한 장면에서 「버큭」으로 보이던 글자를 고쳤습니다.
- 「웜」 글자: 「윔」처럼 보이던 글자 그림을 새로 그렸습니다.
- 에프레이에 오르타나 도움말: 설명문 시작 위치가 어긋나 있던 것을 바로잡았습니다.

번역, 표기

- 블리츠볼 아나운서: 전반 종료 대사를 새로 번역했습니다.
- 몬스터 이름: 「어비스 워엄」은 「어비스 웜」, 「랜드 워엄」은 「랜드 웜」으로 바꿨습니다.
- 리키호 전투 적 「비늘 조각」: 이름과 설명이 일본어로 나오던 것을 번역했습니다.
- 알베드 슈터 전투 대사: 일본어로 남아 있던 세 줄을 번역했습니다.
- 소환수 기본 이름: 이름 입력 화면 기본값이 「발파레」, 「이프리트」로 나옵니다. 이전에는 깨진 글자가 나왔습니다.
- 패치 안내 화면: 제목을 v0.2.0 으로 바꿨습니다.

## 알아 두실 점

- 원본 ISO 는 바뀌지 않고 새 파일이 만들어집니다. 빈 공간이 4.7GB 이상 필요합니다.
- 캐릭터와 소환수 이름은 세이브에 저장됩니다. 옛 세이브에서는 일부 이름이 예전 표기로 남을 수 있습니다. 이름 입력 화면에서 초기화 후 결정하면 새 표기로 바뀝니다.
- 이 패치는 일본판 인터내셔널 전용입니다. 북미판, 유럽판, HD 리마스터에는 쓸 수 없습니다.
