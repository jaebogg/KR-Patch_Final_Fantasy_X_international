# 파이널 판타지 X 인터내셔널 한글패치

## 원본 ISO

- 게임: Final Fantasy X International (일본판, SLPS-25088)
- 크기: 4,613,767,168 바이트
- 원본 MD5: `4033e9f641f0385f42fb9e04a20adbbe`
- 적용 결과 MD5: `c478682a1cbda56139c318f2f7e7caeb`

원본 MD5 가 다르면 적용되지 않습니다.

## 적용 방법

1. zip 파일을 빈 폴더에 풉니다.
2. 원본 ISO 를 같은 폴더에 넣습니다.
3. `패치적용.bat` 를 더블클릭합니다. 원본 ISO 를 bat 파일 위로 끌어다 놓아도 됩니다.
4. 잠시 뒤 `FFX_International_JP_KOR.iso` 가 생깁니다.

## 알아 두실 점

- 원본 ISO 는 바뀌지 않고 새 파일이 만들어집니다. 빈 공간이 4.7GB 이상 필요합니다.
- 캐릭터와 소환수 이름은 세이브에 저장됩니다. 옛 세이브에서는 일부 이름이 예전 표기로 남을 수 있습니다. 이름 입력 화면에서 초기화 후 결정하면 새 표기로 바뀝니다.
- 이 패치는 일본판 인터내셔널 전용입니다. 북미판, 유럽판, HD 리마스터에는 쓸 수 없습니다.
